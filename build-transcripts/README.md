# Build transcripts — Thesis

Records of how this project was built, prepared for the interviewer.

| File | What it is |
| --- | --- |
| `user-brief.md` | The assignment brief and design requirements, as received. |
| `session-log.md` | Chronological activity log of implementation work (observable actions, not reasoning). |
| `decisions.md` | Architecture choices and the tradeoffs behind them. |
| `validation.md` | Commands run, their outcomes, and unresolved issues. |
| `handoff.md` | Setup, deployment status, reviewer URL, limitations. |
| `transcripts/` | Exported agent conversation transcripts (see `transcripts/README.md` for provenance and export instructions). |

Nothing in this folder contains API keys, credentials, environment values, or hidden chain-of-thought. Application research logs (what the product records about a research job) live in the app itself and are separate from these build records.
